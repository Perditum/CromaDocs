# Croma Pro

## What is this?
Croma Pro is a more advanced version of the Croma bot for bigger servers. It gives moderators access to more features to moderate their servers. Croma Pro Lite is the same thing, but has a smaller barrier of entry.

## Whwt are the feature differences?
Croma Pro includes voice logs, server lookup, a seperate bot, filters and link redirect resolving. Croma Pro Lite also includes most of those features, but excludes link resolving, the seperate bot and server lookup.

## Features
- Voice logs show you when members join and leave voice chats.
- Server lookups allow you to find info on external servers without joining through their server ID or an invite.
- The pro bot gives you faster update times and bragging points. (You can still use the normal bot, the pro bot is not required)
- Filters let you fine grain the already existing automod features.
- Link resolving stops users from using link shorteners from hiding their invite links.
- And more to be added...

## How do I get it?
Croma Pro is available to servers using Croma with more than 350 members free of charge. Croma Pro Lite is available to servers using Croma with more than 100 members free of charge.

If you would like to get it before these limits, or if you have specific requirements, contact us on our support server found on our homepage.
